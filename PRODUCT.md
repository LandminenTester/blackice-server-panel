# Unofficial REPLAY.re - Server Webpanel
Public dashboard for Replay server administrators. One administrator and one managed server per installation. Windows ConPTY, Linux PTY and Docker Engine backends. Protected first-run setup, official installation, typed English/German locales, server controls, console, logs and truthful bundle state. Default localhost:20772; optional HTTPS proxy. User-approved design: dark Cyberpunk-inspired surfaces, angular red contours, cyan information and selective yellow action accents. 

Direct Start executables hold an interactive control terminal. Native managed servers expose a separate terminal; Docker does not. Auto-start is a persisted setting. Closing control stops the stack; closing the server terminal stops the game. SSH uses tmux.
