# Unofficial BlackICE - Server Webpanel
Public unofficial dashboard for BlackICE server administrators. Multiple accounts with individual permissions and one managed server per installation. Windows ConPTY, Linux PTY and Docker Engine backends. Protected first-run setup, official installation, typed English/German locales, server controls, console, logs and truthful bundle state. Default localhost:20772; optional HTTPS proxy. User-approved design: dark Cyberpunk-inspired surfaces, angular red contours, cyan information and selective yellow action accents.

Direct Start executables hold an interactive control terminal. Native managed servers expose a separate terminal; Docker does not. Auto-start is a persisted setting. Closing control stops the stack; closing the server terminal stops the game. SSH uses tmux.

Accounts now support individual server, console, log, bundle, settings and user-management permissions. The existing administrator retains full access. Users with user-management permission can manage accounts; the last enabled manager is protected. Native terminal control remains local OS authority.
