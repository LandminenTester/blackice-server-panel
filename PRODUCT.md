# Unofficial BlackICE - Server Webpanel
Public unofficial dashboard for BlackICE server administrators. Multiple accounts with individual permissions and one managed server per installation. Windows ConPTY, Linux PTY and Docker Engine backends. Protected first-run setup, official installation, typed English/German locales, server controls, console, logs and truthful bundle state. Default localhost:20772; optional HTTPS proxy. User-approved design: dark Cyberpunk-inspired surfaces, angular red contours, cyan information and selective yellow action accents.

Direct Start executables hold an interactive control terminal. Native managed servers expose a separate terminal; Docker does not. Auto-start is a persisted setting. Closing control stops the stack; closing the server terminal stops the game. SSH uses tmux.

Accounts now support individual server, console, log, bundle, settings and user-management permissions. The existing administrator retains full access. Users with user-management permission can manage accounts; the last enabled manager is protected. Native terminal control remains local OS authority.

Native installations can recover a moved server through Settings → General by validating and saving its absolute directory while stopped; global missing-directory/executable feedback links there, preserves Stop while running, and blocks Start/Restart until recovery. This changes backend and bundle paths without moving files or forcing restarts; Docker instead explains deployment-controlled mounts in a read-only directory view.

The bounded diagnostic/bridge/update extension preserves the user-pinned visual identity and fixed Full HD operation shell. Console now offers permission-filtered diagnostic source/module/search, pause/resume, follow, retained history and download of the filtered output. The optional MCP bridge uses `--mcp-dangerous-allow-server-listing` without forcing LAN mode; existing `sv_lan` and network settings still control public listing, exposes separate transport/health/phase/build/tick/reply/exit information and retains PTY/ConPTY fallback. RE Server updates check and prepare available official-alpha releases or local backups, then require confirmation before applying a ready job; arbitrary historical downloads are not promised. Existing product-schema and route drift are outside this extension's scope.
