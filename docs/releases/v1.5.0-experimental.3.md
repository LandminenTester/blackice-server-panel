# BlackICE Panel 1.5.0-experimental.3

Includes the Docker fixes from stable 1.4.1 alongside the existing experimental bundle workflows:

- Automatic persistent permissions for server configuration, settings and bundle files; no manual ownership workaround in the bundle-build tests.
- Verified panel installation through the Docker dashboard, persistent runtime selection, readiness checks and automatic rollback. Panel updates leave the game running.
- Docker frontend startup, console reattachment after external game restarts, and `keep-running` on Supervisor restart.
- Game startup preserves dashboard-managed settings.
- A standalone Docker bundle with the image, matching version, Compose file and startup script: extract and run `sh scripts/docker.sh`.

Existing Docker deployments need the current entrypoints, role labels, shared mounts and updater setting once. See `docs/docker.md`. This remains an experimental release; stable users receive 1.4.1 without the experimental bundle features.
