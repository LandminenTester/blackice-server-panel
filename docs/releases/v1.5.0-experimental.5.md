# BlackICE Panel 1.5.0-experimental.5

## English

- Native and Docker bridge startup now use `--mcp-dangerous-allow-server-listing` instead of the old LAN-only `--mcp` flag.
- Docker replaces old managed MCP flags and endpoint/token arguments instead of accumulating duplicate bridge settings. Disabling the bridge removes both old and new flags.
- Settings and documentation now call the feature **MCP bridge**. The local/private listener and token authentication remain in place.
- The bridge flag no longer itself forces LAN mode. Public listing still depends on your existing `sv_lan` and network configuration; the panel does not rewrite these settings. Updated official server files supporting the new flag are required.

Apply startup changes with an explicit game-server restart after updating the panel. Saving settings or updating the panel does not itself switch the running game's launch arguments.

Includes the NuGet source-version display, package-dialog shortcut and exact-pin preservation from experimental.4. Local bridge tests cover new startup arguments, Docker migration, disablement and idempotence. Real Windows/Linux/Docker bridge checks run in release CI; this is not proof of a particular server appearing in the public list.

## Deutsch

- Native Bridge-Starts und Docker verwenden jetzt `--mcp-dangerous-allow-server-listing` anstelle des alten LAN-Parameters `--mcp`.
- Docker ersetzt alte verwaltete MCP-Parameter samt Adresse und Token, statt doppelte Bridge-Einstellungen anzuhängen. Beim Deaktivieren verschwinden alte und neue Parameter.
- Einstellungen und Dokumentation nennen die Funktion jetzt **MCP-Bridge**. Lokale/private Verbindung und Token-Anmeldung bleiben erhalten.
- Der Bridge-Parameter erzwingt selbst keinen LAN-Modus mehr. Öffentliche Listung hängt weiterhin von `sv_lan` und der Netzwerkkonfiguration ab; das Panel verändert diese Einstellungen nicht. Aktuelle offizielle Serverdateien mit Unterstützung für den neuen Parameter sind erforderlich.

Nach dem Panel-Update einen ausdrücklichen Spielserver-Neustart auslösen, um die neuen Startparameter zu übernehmen. Speichern oder Panel-Updates ändern die Startparameter des bereits laufenden Spiels nicht.

Enthält außerdem die NuGet-Quellversionen, den Paketdialog-Direktzugriff und den Erhalt exakter Paketbindungen aus experimental.4. Lokale Bridge-Tests prüfen Startparameter, Docker-Umstellung, Deaktivierung und wiederholte Anwendung. Echte Windows-/Linux-/Docker-Bridge-Prüfungen laufen in der Release-CI; eine konkrete öffentliche Serverlistung wird damit nicht nachgewiesen.
