# BlackICE Panel 1.5.0-experimental.4

## English

- Project rows now show declared BlackICE NuGet source versions and a direct **NuGet** button for checking available versions and proposing an update in a linked repository.
- Package updates use the existing isolated branch and pull/merge request workflow. Exact NuGet pins such as `[1.1.0]` remain exact when updated to `[1.2.0]`.
- Package displays explicitly distinguish source declarations from the installed bundle. Merge the update request, then use **Pull & Build** to install the changed bundle. Committed package lock files still need to be refreshed and verified in the repository's build workflow.

Local validation: 216 core checks passed, Svelte check passed without errors or warnings, and the production UI build passed. Windows, Linux and Docker release validation runs in GitHub Actions before publication.

Bundle Tools remain experimental and require the experimental update channel. This release does not automatically update game servers, bundle sources or BlackICE SDK packages.

## Deutsch

- Projektzeilen zeigen jetzt die deklarierten BlackICE-NuGet-Versionen der Quellen und einen direkten **NuGet**-Button zum Prüfen verfügbarer Versionen und Vorschlagen eines Updates im verknüpften Repository.
- Paketupdates verwenden den vorhandenen isolierten Branch mit Pull-/Merge-Request. Exakte NuGet-Bindungen wie `[1.1.0]` bleiben beim Update auf `[1.2.0]` exakt.
- Die Paketanzeige unterscheidet ausdrücklich zwischen Quellen und installiertem Bundle. Nach der Übernahme der Update-Anfrage installiert **Pull & Build** das geänderte Bundle. Eingecheckte Paket-Locks müssen weiterhin im Build-Ablauf des Repositorys aktualisiert und geprüft werden.

Lokal geprüft: 216 Core-Prüfungen bestanden, Svelte-Prüfung ohne Fehler oder Warnungen und erfolgreicher Produktionsbuild der UI. Die Release-Prüfungen für Windows, Linux und Docker laufen vor der Veröffentlichung in GitHub Actions.

Bundle-Tools bleiben experimentell und benötigen den experimentellen Update-Kanal. Dieses Release aktualisiert weder Spielserver noch Bundle-Quellen oder BlackICE-SDK-Pakete automatisch.
